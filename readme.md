# Laundry Wallah Website

## Project Overview
Laundry Wallah is a simple HTML-based laundry service website designed to provide customers with information about available laundry services, pricing details, and an online booking form.

The website serves as a basic front-end project for practicing HTML concepts such as headings, images, tables, forms, lists, and page structure.

## How to Run

1. Download or clone the project.
2. Open the `index.html` file in any web browser.
3. The website will load and display all sections.
